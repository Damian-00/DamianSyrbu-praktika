Инструкция по использованию кода:

Установи Python (версия 3.7+).

Установи нужные библиотеки в терминале.

Создай папку статьи в той же директории, где лежит скрипт.

Скопируй PDF-файлы в папку статьи.

Сохрани код в файл analyzer.py.

Запусти программу: в терминале python analyzer.py.

После выполнения появится файл result.json с результатами (статистика + контекст предложений).

Чтобы изменить корни — отредактируй список ROOTS в коде.
