Код, json и статьи(PDF-файлы) лежат в папке "Статьи".
Что делает программа:
Программа ищет количество слов встречающиеся в тексте по корням и выводит в json. В json можно увдиеть общую статистику количество встречаемых 4 корней, статистику по файлам , то есть сколько встречаеться в каждом файле и есть подробная статистика, которая выводит название файла,корень слова, само слово, страница где находиться, авторов и предложения, где находиться слово.

Инструкция по использованию кода:

Скачайте папку "статьи" и откройте в VS Code

Установить нужные библиотеки в терминале, которые есть в коде(1.py).

PDF-файлы уже лежат в папке "статьи", если хотите другие , то скачайте PDF-файлы и положи их в папку статьи.

Запустить программу

После выполнения появится файл result.json с результатами (общая статистика + статистика + контекст предложений).

Если хотите, чтобы другие слова искались, то измените корни — отредактируй список ROOTS в коде.
